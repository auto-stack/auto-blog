# Auto Blog：业界调研

日期：2026-10-04；个人写作和发布工作流优先，社区运营后置。

| 来源 | 核实内容 | 决策 |
|---|---|---|
| [Ghost 发布与预览](https://ghost.org/help/publishing-content/) | 编辑器进入不同显示场景的预览，并有独立发布/定时入口 | 写作、预览、发布三步分开；首版桌面/窄屏预览，先完成本地导出 |
| [Ghost 导出](https://ghost.org/help/exports/) | 内容/数据有导出路径 | 草稿、发布版、附件与来源可迁出；不把内容关在一种UI或社区里 |
| [Readwise Reader 导出](https://docs.readwise.io/reader/docs/faqs/exporting) | 带书源的摘录可导出至笔记应用 | 阅读/笔记输入作为有引用的写作资料，不自动把源笔记改成文章 |

编辑能力复用AutoDown是生态架构决策，并非Ghost提供的Auto集成。v0.6首版不复制完整WordPress/Ghost后台，不承诺邮件投递、付费会员、评论审核和推荐市场。现有RealWorld社交demo留作参考，不把它的演示鉴权当生产社区基础。
